# Nhật Ký Công Việc Hoàn Thành - 19/07/2026

Hôm nay, chúng ta đã thực hiện các cải tiến quan trọng về cơ sở dữ liệu, tối ưu hiệu năng tải trang ở Frontend và thiết lập tài liệu quy trình làm việc chuẩn. Chi tiết cụ thể như sau:

---

## 1. Di Chuyển Cơ Sở Dữ Liệu Lên Đám Mây (Supabase Cloud)
*   **Vấn đề gặp phải:** Máy chủ Supabase chính chỉ hỗ trợ địa chỉ IPv6 (AAAA record) nên môi trường mạng local IPv4 không thể kết nối trực tiếp, báo lỗi `P1001: Can't reach database server`.
*   **Giải pháp xử lý:** 
    *   Tạo script kiểm tra tự động kết nối qua cổng Session Pooler của AWS.
    *   Xác định vùng dự án nằm ở **Tokyo (`ap-northeast-1`)** và kết nối thành công qua cổng **5432**.
    *   Cập nhật cấu hình file `backend/.env` với đường dẫn kết nối Supabase Pooler mới.
*   **Kết quả:** 
    *   Đồng bộ schema thành công bằng lệnh `npx prisma db push`.
    *   Seed thành công toàn bộ dữ liệu lý thuyết và danh sách bài tập thực hành lên cơ sở dữ liệu đám mây thông qua `npx prisma db seed` và `seed_problems.ts`.

---

## 2. Phân Tích Và Khắc Phục Độ Trễ Tải Trang (~3 giây)
*   **Nguyên nhân độ trễ:**
    1.  **Độ trễ vật lý (Network Latency):** Cơ sở dữ liệu đặt ở Nhật Bản nên việc bắt tay bảo mật SSL lần đầu tiên tốn gần 1 giây, các lượt truy vấn đơn lẻ mất khoảng 100ms - 200ms.
    2.  **Truy vấn lồng quá sâu:** Logic cũ trong API lấy bài học (`getLessonById`) thực hiện `include` tuần tự qua 5 tầng thực thể chỉ để tìm bài tiếp theo, gây quá tải dữ liệu.
    3.  **Vite Dev Mode:** Vite local biên dịch và nạp file TypeScript theo yêu cầu (on-demand loading) ở lần đầu tiên chuyển trang.
*   **Giải pháp khắc phục đã triển khai:** Tích hợp bộ nhớ đệm (Caching) tại Frontend.

---

## 3. Tích Hợp TanStack Query (React Query)
*   **Cài đặt:** Cài đặt thư viện `@tanstack/react-query` phiên bản v5.
*   **Cấu hình (`App.tsx`):**
    *   Khởi tạo `QueryClient` với cấu hình lưu cache trong **5 phút** (`staleTime`) và dọn dẹp cache sau **10 phút** (`gcTime`).
    *   Bọc ứng dụng trong `QueryClientProvider`.
*   **Chuyển đổi giao diện:**
    *   **`Dashboard.tsx`:** Sử dụng `useQuery` để tự động nạp và lưu cache danh sách khóa học. Tích hợp hiệu ứng loading nhấp nháy (`animate-pulse`) và xử lý trạng thái trống (empty state).
    *   **`CourseDetail.tsx`:** Thay thế `useEffect` thủ công bằng `useQuery` với key `['course', id]`. Giúp mở chi tiết khóa học tức thì trong 0ms nếu đã từng vào trước đó.
    *   **`Lesson.tsx`:** Chuyển đổi API chi tiết bài học sang `useQuery` với key `['lesson', id]`. Rút gọn code, loại bỏ các state thừa (`hasExercise` được tính toán động).
*   **Kiểm tra:** Đã chạy kiểm tra kiểu dữ liệu toàn bộ Frontend (`npx tsc --noEmit`) và hoàn toàn không có lỗi biên dịch nào.

## 4. Tài Liệu Quy Trình Làm Việc Với Git
*   Tạo file tài liệu **`quy_trinh_git.md`** tại thư mục gốc của dự án.
*   Hướng dẫn chi tiết quy trình tạo nhánh tính năng mới (`feature/*`), quy tắc đặt tên commit, cách xem lịch sử, cách khôi phục/hủy bỏ các thay đổi cũ (`checkout`, `revert`, `reset`), và sử dụng thẻ phiên bản (`tag`) để dễ dàng quản lý mã nguồn khi tiếp tục phát triển ứng dụng.

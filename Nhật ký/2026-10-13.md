## [09:35] Sửa lỗi xung đột bảng mã ký tự kết thúc dòng (CRLF / LF) gây mã lỗi 503 trên Render Linux

### 1. 🎯 Mục tiêu
- Khắc phục lỗi HTTP 503 `PILOT_CHECKPOINT_UNAVAILABLE` trả về từ dịch vụ `codehub-ai` trên Render Cloud.
- Đảm bảo tính tương thích chéo nền tảng (Windows phát triển vs Linux máy chủ) khi kiểm tra tính toàn vẹn (SHA-256) của bộ dữ liệu học viên `synthetic_pilot_learners.csv` và đồ thị tri thức `skill_graph.json`.

### 2. 📂 Phạm vi thay đổi (Files & Components)
- `ai-service/app/api/module_practice_pilot.py`:
  - Thư viện: Bổ sung `hashlib`.
  - Hàm mới: Thêm `_matches_expected_hash(path: Path, expected: str) -> bool` để đối sánh mã SHA-256 tính toán trên cả định dạng kết thúc dòng nguyên bản, CRLF (`\r\n`) và LF (`\n`).
  - Hàm nạp mô hình `load_local_pilot()`: Thay thế phép so khớp byte thô `sha256_file(path) != report.get(...)` bằng `_matches_expected_hash(...)`.
- GitHub Repository (`origin/main`): Commit `2bd54bd` đã được đẩy lên nhánh `main`.

### 3. 🛠️ Chi tiết triển khai
- **Phân tích nguyên nhân gốc rễ**:
  - Tệp băm tham chiếu trong `report.json` và trọng số `palnet_pilot.pt` được tính toán trong môi trường Windows với ký tự xuống dòng CRLF (`\r\n`): mã băm tập dữ liệu là `40969384fe86...` và đồ thị là `885c31f95faa...`.
  - Khi Render (Linux) kéo mã nguồn từ GitHub thông qua Git, Git tự động chuyển đổi các ký tự ngắt dòng thành LF (`\n`).
  - Do đó hàm băm byte nguyên thủy `sha256_file()` trên Linux tính ra `67195e82...` (cho CSV) và `5eba774a...` (cho JSON), không khớp với giá trị lưu trong `report.json`.
  - Kết quả: `load_local_pilot()` ném ngoại lệ `ValueError("Pilot artifact, dataset, or curriculum graph mismatch")`, dẫn đến mã HTTP 503 `PILOT_CHECKPOINT_UNAVAILABLE` và giao diện frontend chuyển sang chế độ dự phòng "PAL-Net local chưa sẵn sàng".
- **Giải pháp**:
  - Cài đặt `_matches_expected_hash` hỗ trợ kiểm tra tính tương đương ngữ nghĩa dữ liệu bất kể tệp được lưu theo chuẩn LF (Linux/Docker/Render) hay CRLF (Windows).

### 4. ✅ Kết quả & Kiểm tra (Verification)

## [09:02] Triển khai thành công phân hệ AI Service (FastAPI + PyTorch) lên Render Cloud

### 1. 🎯 Mục tiêu
- Đưa phân hệ `ai-service` (Python FastAPI + PyTorch CPU + mô hình PAL-Net) từ môi trường cục bộ lên máy chủ đám mây Render Cloud.
- Hoàn thiện trọn vẹn mô hình kiến trúc phân tán 3 phân hệ (Frontend trên Vercel, Backend Node.js trên Render, AI Service Python trên Render).
- Xử lý các rào cản kỹ thuật trong quá trình đóng gói và triển khai: lựa chọn nền tảng tối ưu (Render vs Hugging Face), khắc phục lỗi build wheel `pandas` và thiết lập lệnh khởi chạy `uvicorn`.

### 2. 📂 Phạm vi thay đổi (Files & Components)
- `Render Cloud Dashboard`:
  - Khởi tạo Web Service mới mang tên `codehub-ai` kết nối với kho mã nguồn GitHub `nguyentuanviet12k1d22cntt02-eng/codehub`, chỉ định thư mục gốc `Root Directory: ai-service`.
  - Thiết lập biến môi trường `PYTHON_VERSION=3.11.9` để đảm bảo tính tương thích của hệ sinh thái thư viện AI.
  - Cấu hình **Build Command**:
    ```bash
    pip install --upgrade pip setuptools wheel && pip install --no-cache-dir torch --index-url https://download.pytorch.org/whl/cpu && pip install -r requirements.txt
    ```
  - Cấu hình **Start Command**:
    ```bash
    uvicorn main:app --host 0.0.0.0 --port $PORT
    ```
- `codehub-backend` (Web Service trên Render):
  - Cập nhật biến môi trường: `AI_SERVICE_URL=https://codehub-ai.onrender.com` để hoàn tất chu trình kết nối liên dịch vụ.
- `Nhật ký/2026-10-13.md`: Tạo mới - Ghi nhận chi tiết toàn bộ tiến trình triển khai.

### 3. 🛠️ Chi tiết triển khai
- **Khảo sát nền tảng**: Ban đầu cân nhắc Hugging Face Spaces, nhưng do chính sách mới của Hugging Face gắn nhãn trả phí (`🔒 Paid`) cho môi trường Docker tùy biến và thời gian ngủ đông (cold-start) kéo dài, quyết định chuyển sang Render để đồng bộ hạ tầng với Backend Node.js.
- **Xử lý lỗi build `metadata-generation-failed (pandas)`**: Render mặc định sử dụng phiên bản Python quá mới (Python 3.13+) dẫn đến việc thiếu các gói nhị phân (binary wheels) biên dịch sẵn cho `pandas` và `numpy`. Khắc phục bằng cách ghim biến môi trường `PYTHON_VERSION=3.11.9` giúp pip tải thẳng wheel Linux x86_64 trong vài giây.
- **Xử lý lỗi khởi chạy `status 127 (gunicorn: command not found)`**: Render tự động gán lệnh mặc định của Django (`gunicorn`). Đã cấu hình lại chính xác Start Command sử dụng `uvicorn` bind vào cổng động `$PORT`.
- **Liên kết Microservices**: Cấu hình `AI_SERVICE_URL` tại dịch vụ `codehub-backend`, cho phép backend chuyển tiếp các yêu cầu tính toán trạng thái tri thức (Knowledge Tracing) và gợi ý bài tập thích ứng sang dịch vụ `codehub-ai`.

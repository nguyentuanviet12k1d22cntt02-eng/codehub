## **Bài tập về Slicing trong Python (Dành cho Chuỗi)**

### **Bài tập 1: Trích xuất một phần của chuỗi**

- **Yêu cầu:** Cho chuỗi `s = "Hello, World!"`. Sử dụng slicing để trích xuất từ "World".
- **Ví dụ đầu ra:**
    
    ```
    World
    
    ```
    

### **Bài tập 2: Lấy ký tự ở vị trí cụ thể**

- **Yêu cầu:** Cho chuỗi `s = "Python"`. Sử dụng slicing để trích xuất ký tự thứ hai và ký tự thứ tư.
- **Ví dụ đầu ra:**
    
    ```
    y
    h
    
    ```
    

### **Bài tập 3: Đảo ngược chuỗi**

- **Yêu cầu:** Cho chuỗi `s = "Python"`. Sử dụng slicing để đảo ngược chuỗi.
- **Ví dụ đầu ra:**
    
    ```
    nohtyP
    
    ```
    

### **Bài tập 4: Trích xuất các ký tự với bước nhảy**

- **Yêu cầu:** Cho chuỗi `s = "123456789"`. Sử dụng slicing để trích xuất các ký tự ở vị trí lẻ (bắt đầu từ vị trí 1).
- **Ví dụ đầu ra:**
    
    ```
    13579
    
    ```
    

### **Bài tập 5: Slicing với chỉ số âm**

- **Yêu cầu:** Cho chuỗi `s = "Hello, World!"`. Sử dụng slicing với chỉ số âm để trích xuất từ "World".
- **Ví dụ đầu ra:**
    
    ```
    World
    
    ```
    

### **Bài tập 6: Trích xuất một phần chuỗi từ đầu**

- **Yêu cầu:** Cho chuỗi `s = "Programming"`. Sử dụng slicing để trích xuất 5 ký tự đầu tiên.
- **Ví dụ đầu ra:**
    
    ```
    Progr
    
    ```
    

### **Bài tập 7: Trích xuất một phần chuỗi từ cuối**

- **Yêu cầu:** Cho chuỗi `s = "Programming"`. Sử dụng slicing để trích xuất 6 ký tự cuối cùng.
- **Ví dụ đầu ra:**
    
    ```
    amming
    
    ```
    

### **Bài tập 8: Slicing để loại bỏ ký tự đầu và cuối**

- **Yêu cầu:** Cho chuỗi `s = "[Python]"`. Sử dụng slicing để loại bỏ dấu `[` ở đầu và dấu `]` ở cuối.
- **Ví dụ đầu ra:**
    
    ```
    Python
    
    ```
    

### **Bài tập 9: Slicing với bước nhảy lớn**

- **Yêu cầu:** Cho chuỗi `s = "0123456789"`. Sử dụng slicing để trích xuất các ký tự với bước nhảy 3, bắt đầu từ vị trí 0.
- **Ví dụ đầu ra:**
    
    ```
    0369
    
    ```
    

### **Bài tập 10: Trích xuất xen kẽ và đảo ngược**

- **Yêu cầu:** Cho chuỗi `s = "abcdefghij"`. Sử dụng slicing để trích xuất các ký tự ở vị trí chẵn, sau đó đảo ngược kết quả.
- **Ví dụ đầu ra:**
    
    ```
    jhfdb
    
    ```
